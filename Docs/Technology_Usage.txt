2. XÁC THỰC (AUTHENTICATION) — JWT + BCRYPT
================================================================================

📌 Công nghệ:
  - jsonwebtoken (JWT): Tạo và xác thực token
  - bcrypt: Hash password
  - localStorage: Lưu token phía client

📁 File liên quan:
  - backend/middlewares/users.middleware.js (auth middleware)
  - backend/routes/users.routes.js (signup/login/logout)
  - backend/blacklist.js (token blacklist in-memory)
  - frontend/src/components/LogIn.jsx
  - frontend/src/components/SignUp.jsx
  - frontend/src/Redux/UserReducer/ (store state)

⚙️ Quy trình:
  Đăng ký:
    1. User nhập name, email, password, age, city, job
    2. Backend hash password bằng bcrypt (salt rounds = 5)
    3. Lưu user vào MongoDB
    4. Tạo JWT với payload { userId, user, role }
    5. Trả về token + user info

  Đăng nhập:
    1. User nhập email + password
    2. Backend tìm user trong DB
    3. So sánh password với bcrypt.compare
    4. Tạo JWT mới
    5. Trả token và lưu vào Redux + localStorage

  Xác thực request (middleware auth):
    1. Đọc header "Authorization: Bearer <token>"
    2. Kiểm tra token có trong blacklist không
    3. Verify JWT với secret "SRM"
    4. Gán userId, username, role vào req.body

  Đăng xuất:
    1. Thêm token vào blacklist (mảng in-memory)
    2. Xóa localStorage
    3. Reset Redux state

🔐 JWT Secret:
  - Dùng 2 loại secret: "SRM" (xác thực chính) và "ARIVU" (refresh token)
  - Refresh token tại /regenerateToken

  Làm quiz (Student):
    1. Chọn video → GET /quizzes/video/:videoId

    3. Backend so sánh từng đáp án với correctIndex

  Kiểm tra quyền:
    - canUserAccessCourseContent(): kiểm tra enrollment trước khi cho làm quiz
    - Nếu chưa enroll → 403 Forbidden

  - frontend/src/Pages/CertificatesPage.jsx (hiển thị + download)
  - frontend/src/Pages/CourseLearnPage.jsx (nút "Get My Certificate")

  1. User phải ENROLL trong khóa học
  2. User phải SUBMIT QUIZ cho TẤT CẢ video trong khóa học
  3. Điểm trung bình (best score mỗi video) >= 80%

⚙️ Quy trình:
  Check eligibility:
    GET /certificate/check/:courseId
    → Trả về: hasCertificate, eligible, videosCompleted/totalVideos, averageScore

  Issue:
    POST /certificate/issue/:courseId
    → Tạo certificateId: "CERT-" + timestamp(36) + random(4)
    → Tạo certificateNumber: "EL" + timestamp(4) + random(4)
    → Lưu vào DB → trả certificate

  Download PNG:
    1. frontend tạo div ẩn với HTML certificate template
    2. html2canvas chụp div đó (scale 2x cho HD)
    3. Tạo link download → click tự động
    4. File name: certificate-[certificateNumber].png

📌 Định dạng certificate HTML:
  - Khung viền vàng (border 8px #DAA520)
  - Icon 🎓
  - "Certificate of Completion"
  - Student name, course name, ngày cấp
  - Certificate ID + Number ở cuối

⚙️ Kiến trúc RAG:
  1. Upload: Teacher/Admin upload PDF
     → Backend extract text bằng pdf-parse
     → Lưu text vào backend/data/course_[courseId].txt

  2. Hỏi đáp:
     → Student gửi câu hỏi
     → Backend load context từ file .txt
     → Build system prompt: yêu cầu AI CHỈ trả lời trong context
     → Gọi Gemini API
     → Kiểm tra isAnswerWithinContext()
     → Nếu ngoài context → thông báo "không nằm trong nội dung khóa học"

📌 System Prompt:
  - Yêu cầu AI trả lời bằng tiếng Việt
  - Strict: chỉ dùng nội dung khóa học được cung cấp
  - Nếu không chắc chắn → nói "không được đề cập trong khóa học"

📌 Các format response Gemini được hỗ trợ:
  1. response.text (SDK cũ)
  2. response.candidates[0].content.parts[0].text (SDK v2)
  3. response.response.candidates[0]... (nested)

PHỤ LỤC: "views" TRONG VIDEO MODEL CÓ TÁC DỤNG GÌ?
================================================================================

📌 Phát hiện:
  Trong backend/models/video.model.js có trường:
    views: { type: Number, default: 0 }

📌 Trả lời: HIỆN TẠI KHÔNG CÓ TÁC DỤNG GÌ.

🔍 Lý do:
  - Trường "views" được định nghĩa trong schema nhưng KHÔNG được sử dụng
    ở bất kỳ đâu trong toàn bộ codebase:
    + Không có API endpoint nào increment views
    + Không có logic nào cập nhật views khi user xem video
    + Không có giao diện nào hiển thị số views
  - Đây là trường "dead code" — được định nghĩa nhưng chưa implement

💡 Nếu muốn sử dụng "views" trong tương lai, có thể triển khai:
  Ví dụ code đề xuất:

  // backend/routes/videos.route.js — thêm endpoint
  videoRoute.patch("/increment-views/:videoId", auth, async (req, res) => {
    try {
      const videoId = req.params.videoId;
      const video = await VideoModel.findByIdAndUpdate(
        videoId,
        { $inc: { views: 1 } },   // Tăng views lên 1
        { new: true }
      );
      res.status(200).json({ views: video.views });
    } catch (err) {
      res.status(400).json({ message: err.message });
    }
  });

  // frontend — gọi khi user bắt đầu xem video
  // Trong CourseLearnPage.jsx, thêm useEffect khi activeIndex thay đổi:
  useEffect(() => {
    if (activeVideoId && token) {
      fetch(`/videos/increment-views/${activeVideoId}`, {
        method: "PATCH",
        headers: { authorization: `Bearer ${token}` }
      });
    }
  }, [activeVideoId]);

📌 Kết luận:
  views chỉ là schema định nghĩa sẵn cho tương lai.
  Hiện tại không ảnh hưởng gì đến hệ thống, không cần lo lắng.
  Nếu muốn dùng, cần implement thêm endpoint + gọi từ frontend.
