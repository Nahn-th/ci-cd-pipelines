1. backend/index.js
────────────────────────────────────────────────────────────────────────────────
📌 Ý nghĩa: File khởi động chính của Backend server (Express.js).

🔧 Chức năng:
  - Khởi tạo Express app
  - Cấu hình CORS, JSON parser
  - Đăng ký tất cả các route:
    /users, /courses, /videos, /quizzes, /payment, /certificate, /ai-assistant

  - Lắng nghe ở port 5001 (hoặc PORT từ .env)

⚙️ Logic quan trọng:

  - Xử lý lỗi EADDRINUSE (port đã được dùng)

6. backend/middlewares/users.middleware.js
────────────────────────────────────────────────────────────────────────────────
📌 Ý nghĩa: Middleware xác thực JWT.

🔧 Chức năng:
  - Đọc token từ header Authorization
  - Kiểm tra blacklist
  - Verify JWT với secret "SRM"
  - Gán userId, username, role vào req.body

⚙️ Logic quan trọng:
  - Nếu token hết hạn → 401 "not authorized"
  - Nếu token trong blacklist → 401 "Please Login Again"
  - Decoded token chứa: userId, user, role


7. backend/helpers/courseAccess.js
────────────────────────────────────────────────────────────────────────────────
📌 Ý nghĩa: Kiểm tra quyền truy cập nội dung khóa học.

🔧 Chức năng:
  - Hàm canUserAccessCourseContent(userId, courseId)
  - Kiểm tra user đã enroll chưa (user.course có chứa courseId)
  - Admin luôn được truy cập
  - Teacher được truy cập nếu là course của họ

⚙️ Logic quan trọng:
  - Trả về { ok: true, user } nếu được phép
  - Trả về { ok: false, status: 403, code: "NOT_ENROLLED" } nếu không
  - Dùng trong: quiz.route.js, aiAssistant.route.js


8. backend/helpers/aiAssistant.helper.js
────────────────────────────────────────────────────────────────────────────────
📌 Ý nghĩa: Helper tích hợp Google Gemini AI với RAG (Retrieval-Augmented Generation).

🔧 Chức năng:
  - Khởi tạo GoogleGenAI client (nếu có API key)
  - loadCourseContext(courseId): Đọc nội dung khóa học từ file data/course_[id].txt
  - extractTextFromPDF(filePath): Trích xuất text từ file PDF
  - buildSystemPrompt(courseContext): Tạo system prompt với context
  - isAnswerWithinContext(question, answer, context): Kiểm tra câu trả lời có trong phạm vi không
  - queryAIAssistant(courseId, userQuestion): Gọi Gemini API

⚙️ Logic quan trọng:
  - extractResponseText(response): Parse response Gemini dù ở format nào (v1 text, v2 candidates)
  - Fallback nếu không có API key → thông báo thân thiện
  - isAnswerWithinContext: Kiểm tra keyword matching để chống AI "bịa" ngoài context
  - System prompt bằng tiếng Việt, yêu cầu AI chỉ trả lời trong nội dung khóa học

16. backend/routes/users.routes.js
────────────────────────────────────────────────────────────────────────────────
📌 Ý nghĩa: Route xử lý Authentication và User.

🔧 Endpoints:
  - POST /users/signup: Đăng ký (hash password với bcrypt)
  - POST /users/login: Đăng nhập (so sánh password, trả JWT)
  - POST /users/logout: Đăng xuất (thêm token vào blacklist)
  - PATCH /users/update/:id: Cập nhật profile
  - GET /users/enrollment/:courseId: Kiểm tra enrollment

⚙️ Logic quan trọng:
  - JWT chứa: userId, user, role
  - Bcrypt salt rounds = 5
  - Enrollment check: kiểm tra courseId trong user.course


17. backend/routes/courses.route.js
────────────────────────────────────────────────────────────────────────────────
📌 Ý nghĩa: Route CRUD cho Course.

🔧 Endpoints:
  - GET /courses/all: Lấy tất cả course published (public)
  - GET /courses/:courseID: Chi tiết 1 course (public)
  - POST /courses/add: Tạo course (admin/teacher)
  - PATCH /courses/update/:courseID: Sửa course
  - DELETE /courses/delete/:courseID: Xóa course
  - PATCH /courses/approve/:courseID: Duyệt course (admin)
  - PATCH /courses/reject/:courseID: Từ chối (admin)
  - GET /courses/pending: Pending courses (admin)

⚙️ Logic quan trọng:
  - /courses/all chỉ trả về status: "published"
  - Teacher tạo → status = "pending", Admin tạo → status = "published"
  - Hỗ trợ query params: q (search), category, sortBy, sortOrder, page, limit

19. backend/routes/quiz.route.js
────────────────────────────────────────────────────────────────────────────────
📌 Ý nghĩa: Route xử lý Quiz và Submission.

🔧 Endpoints:
  - POST /quizzes/: Tạo/cập nhật quiz (upsert)
  - GET /quizzes/video/:videoId: Lấy quiz (KHÔNG có đáp án)
  - POST /quizzes/video/:videoId/submit: Nộp bài

⚙️ Logic quan trọng (phần quan trọng nhất):
  - canUserAccessCourseContent: Kiểm tra quyền trước khi cho làm quiz
  - Khi GET quiz: ẨN correctIndex khỏi response (chỉ gửi prompt + choices)
  - Khi submit: So sánh answers với correctIndex → tính score + percent
  - Lưu submission với score = percent (0-100)
  - validateQuestionsPayload: Kiểm tra định dạng questions


20. backend/routes/payment.route.js
────────────────────────────────────────────────────────────────────────────────

21. backend/routes/certificate.route.js
────────────────────────────────────────────────────────────────────────────────
📌 Ý nghĩa: Route xử lý Certificate.

🔧 Endpoints:
  - POST /certificate/issue/:courseId: Cấp chứng chỉ
  - GET /certificate/list: Danh sách chứng chỉ của user
  - GET /certificate/:id: Chi tiết 1 chứng chỉ
  - GET /certificate/check/:courseId: Kiểm tra eligibility

⚙️ Logic quan trọng:
  - generateCertificateId(): "CERT-" + timestamp(36) + random(4)
  - generateCertificateNumber(): "EL" + timestamp(4) + random(4)
  - Khi issue: Kiểm tra (1) enrollment, (2) tất cả video có submission, (3) averageScore >= 80%
  - Mỗi video lấy best score từ các lần submit khác nhau
  - Certificate là unique cho mỗi user + course


22. backend/routes/aiAssistant.route.js
────────────────────────────────────────────────────────────────────────────────
📌 Ý nghĩa: Route cho AI Assistant.

🔧 Endpoints:
  - POST /ai-assistant/ask: Hỏi AI về nội dung khóa học
  - POST /ai-assistant/upload-pdf: Upload PDF (admin/teacher)

⚙️ Logic quan trọng:
  - /ask: Kiểm tra enrollment → gọi queryAIAssistant → trả response
  - /upload-pdf: Chỉ admin/teacher → multer nhận file → extract text → lưu data/course_[id].txt
  - Giới hạn file 15MB, chỉ PDF
  - Xóa file tạm sau khi xử lý
